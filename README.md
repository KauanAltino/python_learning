# Projeto de Exercícios de Programação Python

Este repositório contém uma coleção de 10 exercícios de programação, organizados em pastas. 

Cada exercício aborda conceitos de if, elif e else. 

É ideal para quem está aprendendo e praticando suas habilidades.

## Estrutura do Projeto

O repositório está organizado da seguinte forma:

- **📂 Exercício**
- 🖼️ `Arquivo.png` - Imagem contendo o enunciado do exercício 1.
- 📄 `Arquivo.py` - Código principal que resolve o exercício

## Rodando código no terminal

Se quiser apenas rodar os programas, siga os passos abaixo:

Acesse o diretório do exercício usando o terminal.
**1. Por exemplo, para o exercício 1:**

cd Exercício01

**2. Execute o programa com o seguinte comando:**

python vendas.py

**3. Para rodar outros exercícios, basta repetir o processo navegando até a pasta correspondente e executando o código.**

cd ../Exercício02

python tempo_total.py

## Tenha em mente que o nome do arquivo Python muda em cada exercício. Certifique-se de usar o nome correto ao executar o programa.
